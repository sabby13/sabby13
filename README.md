## 🦋 Things I'm Building

> *A tiny world living on your desktop.*

A native Windows screensaver built around a real-time simulated butterfly — exploring the idea of creating the smallest possible "world" an artificial creature could exist inside.

`C#` `WebView2` `Three.js` `Windows`
